安装步骤

  1. 下载安装包。
  2. 双击安装，选择安装目录，默认即可。
  3. 如果 Edge 提示“通常不会下载”：点下载项右侧 ... → “保留”。
  4. 打开安装包后，如果 Windows 提示“已保护你的电脑”：点“更多信息” → “仍要运行”。
  5. 安装完成后双击桌面「FA 无限画布」，可先免费试用 7 天。
  6. 试用到期后，找作者获取卡密并输入。

使用前确认

  • Windows 10 / 11 64 位。
  • 已安装 Microsoft Edge 或 Chrome。
  • 有可正常登录的豆包账号。
  • 生成期间不要锁屏、睡眠或退出托盘。
  • 画布不会自动保存节点布局，做完一段点一次「保存」。
